# Организационный контекст: АО «ИВЦ ЖКХ»

## Описание деятельности

IT-аккредитованная организация (Реестр российского ПО № 26647 от 12.02.2025).

Основные направления:
- Базы данных для предприятий ЖКХ
- Расчёты и начисления платежей (собственное ПО)
- Обработка данных, ведение лицевых счетов
- Автоматический приём платежей, учёт комиссий
- Интеграция с ГИС ЖКХ (программный уровень)
- Файловый обмен с УСЗН (льготные категории)
- Фискализация оплат (наличные + безналичные)
- Отчётность и аналитика
- Абонентский приём
- Удалённый доступ к ПО и БД на серверах ВЦ

## Технологический стек (известный)

- 1С Предприятие 8.3.10.2299
- Собственное ПО (реестр РФ)
- ГИС ЖКХ интеграция
- SQL базы данных

## Правила безопасности для ivc_ai (с учётом контекста)

### КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО

1. Загружать в ИИ реальные данные клиентов (ФИО, адреса, лицевые счета, платежи)
2. Использовать production-базы данных для тестирования моделей
3. Передавать через ИИ реквизиты доступа к ГИС ЖКХ, УСЗН, банковским системам
4. Хранить в vault любые персональные данные (152-ФЗ)
5. Использовать облачные API для обработки данных ЖКХ

### РАЗРЕШЕНО

1. Генерация кода, тестов, документации по абстрактным примерам
2. Ревью кода без реальных данных в контексте
3. Работа с синтетическими/обезличенными датасетами
4. Разработка инструментов автоматизации (не затрагивающих ПДн)
5. Документирование архитектуры и API (без секретов)

### ПРИНЦИП РАБОТЫ С ДАННЫМИ

Если задача требует понимания структуры данных ЖКХ:
1. Создать синтетическую схему БД (без реальных записей)
2. Описать структуру в заметке (поля, типы, связи)
3. Использовать только эту схему для промптов ИИ
4. Никогда не копировать дампы, выгрузки, Excel-файлы с реальными данными в vault

## Compliance

- 152-ФЗ: персональные данные не обрабатываются в рамках ivc_ai
- IT-аккредитация: использовать только российское/открытое ПО (соответствует стеку)
- Реестр ПО РФ: приоритет отечественным решениям при выборе инструментов
- ГИС ЖКХ: интеграционные ключи хранить ТОЛЬКО в KeePassXC, никогда в коде/заметках
