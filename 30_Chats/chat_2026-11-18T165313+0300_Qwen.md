content = r"""@echo off
chcp 65001 >nul
setlocal enabledelayedexpansion

set /p TITLE="Chat title: "

if "%MODEL%"=="" set MODEL=unknown

for /f "tokens=2 delims==" %%a in ('wmic os get localdatetime /value') do set DT=%%a
set DATE=%DT:~0,4%-%DT:~4,2%-%DT:~6,2%

set FILENAME=chat_%DATE%_%TITLE%
set SAFENAME=%FILENAME: =_%

set CONTENT=# %TITLE%^%0A^%0A## Source^%0Amanual^%0A^%0A## Model^%0A%MODEL%^%0A^%0A## Conversation^%0APaste chat content below:^%0A^%0A^%0A## TODO: Extract^%0A- [ ] Выжимка решения → 20_Knowledge^%0A- [ ] Код → code/^%0A- [ ] Карточка скрипта → 40_Cards^%0A- [ ] Удалить секреты перед архивацией

set ENCODED=
call :encode "%CONTENT%" ENCODED

start "" "obsidian://new?vault=ivc_ai&name=30_Chats/%SAFENAME%&content=%ENCODED%"

echo [OK] Note created via Obsidian URI
goto :eof

set "str=%~1"
set "str=%str: =%20%"
set "str=%str:/=%2F%"
set "str=%str:#=%23%"
set "str=%str:[=%5B%"
set "str=%str:]=%5D%"
set "str=%str:&=%26%"

1. Открой Obsidian и посмотрите название vault в левом нижнем углу (рядом с шестерёнкой). Скорее всего там написано `ivc_ai`.
2. В настройках Web Clipper → **Vaults** → удалите текущую запись и добавьте новую, вписав в поле Vault **точно это имя** (без путей, просто `ivc_ai`).
3. Перезагрузите страницу с чатом и попробуйте сохранить снова.

### Если не помогло — проверяем консоль ошибок

Нажмите `Ctrl+Shift+I` в браузере → вкладка **Console**. Попробуйте сохранить заметку ещё раз и скопируйте текст красной ошибки сюда. Это точно укажет причину (неверное имя vault, блокировка CORS или проблема с URI).

### План Б (если клиппер так и не заработает)

Используйте созданный ранее скрипт `save_chat.cmd` — он работает через нативный Obsidian URI и не зависит от настроек расширения:

```
1
C:\ivc_ai\tools\save_chat.cmd
```

Попробуйте исправить имя vault и напишите результат.
