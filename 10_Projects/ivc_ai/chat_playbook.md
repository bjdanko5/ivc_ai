# Playbook: хочу X - скажи чату Y

| Хочу | Скажи чату | Где результат |
|---|---|---|
| Запустить/перезапустить сайт | запусти сайт руководства | tools/run_wiki_lan.py, URL в выводе; [[site_ops]] |
| Поправить этап руководства | внеси X в docs/NN; если меняются команды - обнови 07 и 10 | docs + сайт сам |
| Добавить новый этап/тему | заведи docs/11_... , обнови nav, index и 07 если команды | docs + меню сайта |
| Проверить противоречия | сверь docs с 07 как SSOT | отчёт правок по файлам |
| Заметку не про сервер | создай заметку X в 00_Inbox (или 10_Projects) | заметка с блоком Связи |
| Карточку скрипта | сделай карточку для tools/X | mkcard.py, 40_Cards + code |
| Закоммитить | закоммить и запуш | ivc_git_sync.py |
| Убрать мусор в logs | почисти logs | scan_*.json удалены (генерация отключена) |
| Фильтр в Bases | какие теги у заметок про модели? | tags contains models; UI-фильтр |
| Обновить контекст нового чата | обнови ai_chat_rules | готовый блок для вставки |
| Ручной режим установки | открой 10 walkthrough | 10_Walkthrough_Manual |
| Понять что куда класть | открой vault_map | vault_map |

## Напоминания правил
- Только бесплатные инструменты.
- Новые файлы - через .py в C:\Temp или mknote/mkcard; без PowerShell-многострочников.
- Bases: YAML только name/description/columns/sort; фильтры и колонки - UI.
- Инфраструктурные заметки заканчиваются блоком Связи.
- Код в code/ править в VS Code.
